## Результат

Подготовлены дополнительные release-gates: reusable CI на самом tagged commit до
доступа к release-job, включая четыре ОС/архитектуры, native-access и обязательный uclamp,
стенд четырёх потоков и japicmp. Проверка неизменяемости Central разрешает публикацию
только при HTTP 404; 200, ошибки сети и остальные HTTP-статусы останавливают workflow.

Релиз 1.0.0 не выполнялся: остаются реальные отчёты T-9.1, окончательная заморозка T-9.2,
версия/CHANGELOG 1.0 и успешный запуск обновлённого workflow на GitHub.
