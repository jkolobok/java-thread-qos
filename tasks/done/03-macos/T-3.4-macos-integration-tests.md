## Что сделать

Тесты §49 на platform thread; проверка, что вызов из virtual thread отвергается до native; тест, что `Thread.ofPlatform().start(wrap(...))` не падает.

## Готово, когда

Зелёный `macos-latest` job.

## Результат

`MacOsIntegrationTest` (@EnabledOnOs(MAC), теги `integration`/`abi`): фабрика выбирает провайдер, символы резолвятся, round-trip по классам, последовательный набор на одном потоке, `Thread.ofPlatform().start(wrap(...))`, virtual thread отклоняется до native (carrier не затронут). 11 тестов зелёные локально; `macos-latest` job — после push.
