## Что сделать

В README:

- `DEFAULT` выставляет `QOS_CLASS_DEFAULT`, а не исходный `QOS_CLASS_UNSPECIFIED`;
- после `pthread_setschedparam` (HotSpot `-XX:ThreadPriorityPolicy=1`) вызов вернёт `EPERM`;
- `BACKGROUND` дополнительно throttl'ит I/O и сеть;
- QoS не даёт hard affinity на P/E-ядра.

## Готово, когда

Пункты есть в README-разделе «macOS».

## Результат

Раздел «macOS» в README: DEFAULT ≠ UNSPECIFIED (reset, не restore), EPERM после `pthread_setschedparam` (`-XX:ThreadPriorityPolicy=1`), I/O- и сетевой throttling у BACKGROUND, отсутствие hard affinity на P/E-ядра, независимость QoS от priority.
