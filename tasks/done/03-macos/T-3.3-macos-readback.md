# T-3.3 Readback через qos_class_self()

- **Этап:** Этап 3. macOS
- **Тип:** задача
- **Спецификация:** §7.6
- **Отклонение от спецификации:** нет
- **Зависит от:** [T-3.1](T-3.1-macos-native.md)
- **Блокирует:** [T-3.4](T-3.4-macos-integration-tests.md), [T-7.5](../07-docs-examples/T-7.5-abi-drift-tests.md)
- **Статус:** done

## Что сделать

Downcall `qos_class_self() -> int` (без memory segments) для тестов и capability `nativeReadbackSupported=true`. В публичный API не выносить.

## Готово, когда

Round-trip тест «set → qos_class_self == ожидаемая константа» для всех классов.

## Результат

Downcall `qos_class_self()->int`; `nativeReadbackSupported=true`; в публичный API не вынесен. Round-trip «set → qos_class_self == константа» проходит для всех пяти классов. Наблюдение: новый поток HotSpot возвращает 0x15 (`DEFAULT`), а не `UNSPECIFIED` — зафиксировано в тесте и README.
