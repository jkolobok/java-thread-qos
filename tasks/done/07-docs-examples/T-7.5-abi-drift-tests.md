## Что сделать

Readback-тесты (T-3.3, T-4.4, T-5.6) объявлены как тесты ABI; проверка констант через поведение, без C-компиляции.

## Готово, когда

Тесты помечены и описаны в CONTRIBUTING.

## Результат

Readback-тесты помечены `@Tag("abi")` (`MacOsIntegrationTest.setThenReadBackRoundTrip`, `WindowsIntegrationTest.setThenReadBack`, `LinuxIntegrationTest.setThenReadBackClamps`); layout/constant-тесты выполняются везде. Описано в CONTRIBUTING, раздел «ABI-drift tests». C-компиляции нет.
