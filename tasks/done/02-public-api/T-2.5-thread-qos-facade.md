## Что сделать

Методы: `isSupported()`, `capabilities()`, `set()`, `trySet()` (D-02), `wrap(Runnable)`, `wrap(Callable)`.

- порядок в `set()`: `Objects.requireNonNull` → проверка `isVirtual()` → provider;
- `wrap()` проверяет null аргументов сразу, а virtual thread при выполнении; всегда возвращает обёртку (D-03);
- не трогает interruption status, не вызывает `Thread.setPriority()`;
- `current()` в v1 не включать.

## Готово, когда

Unit-тесты: null → NPE до native; virtual thread → ISE на всех провайдерах; исключение task пробрасывается без изменений; interruption status не меняется.

## Результат

`isSupported()`, `capabilities()`, `set()`, `trySet()`, `wrap(Runnable)`, `wrap(Callable)`. Порядок в `set()`: requireNonNull → isVirtual → provider. `wrap()` всегда возвращает обёртку, строгий. Тесты: NPE до native, ISE на virtual thread (set/trySet/wrap), исключение task пробрасывается тем же экземпляром, interruption status не меняется.
