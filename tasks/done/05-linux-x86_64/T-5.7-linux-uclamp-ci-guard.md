## Что сделать

Убедиться, что хотя бы один Linux job реально проходит uclamp-тесты (проверить `CONFIG_UCLAMP_TASK` на `ubuntu-24.04` runner через `/boot/config-*` или probe).

Отдельный job с флагом «требовать `isSupported()==true`», чтобы регресс не прятался за skip.

## Готово, когда

Job падает, если uclamp-тесты были пропущены.

## Результат

Job `linux-uclamp-required` (ubuntu-24.04, ubuntu-24.04-arm): печатает `CONFIG_UCLAMP_TASK` из `/boot/config-*` и sysctl `sched_util_clamp_*`, запускает `mvn -Dthreadqos.requireSupported=true test` — тесты падают вместо skip, если uclamp недоступен. Локально проверить нельзя (ядро Docker Desktop без uclamp), подтверждение — после push.
