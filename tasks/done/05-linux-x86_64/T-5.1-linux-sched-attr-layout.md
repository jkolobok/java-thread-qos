# T-5.1 LinuxSchedAttr layout

- **Этап:** Этап 5. Linux x86_64
- **Тип:** задача
- **Спецификация:** §13, §52
- **Отклонение от спецификации:** нет
- **Зависит от:** [T-2.8](../02-public-api/T-2.8-ffm-support.md)
- **Блокирует:** [T-5.3](T-5.3-linux-native.md)
- **Статус:** done

## Что сделать

Явный `StructLayout` для `struct sched_attr`: `size`, `sched_policy`, `sched_flags (u64)`, `sched_nice (s32)`, `sched_priority`, `sched_runtime`, `sched_deadline`, `sched_period`, `sched_util_min`, `sched_util_max`.

`SIZE_VER0 = 48`, `SIZE_VER1 = 56`; `VarHandle` на каждое поле.

## Готово, когда

Тест на размер 56, alignment 8 и все offsets.

## Результат

`LinuxSchedAttr.LAYOUT` (56 байт, alignment 8), `SIZE_VER0=48`, `SIZE_VER1=56`, VarHandle на каждое поле, константы policy/flags/errno с ссылкой на UAPI. `LinuxSchedAttrTest`: size, alignment, все offsets (0/4/8/16/20/24/32/40/48/52), ширины, знаковый `sched_nice`.
