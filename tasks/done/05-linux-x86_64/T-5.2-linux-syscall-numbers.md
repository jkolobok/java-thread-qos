- **Этап:** Этап 5. Linux x86_64

- **Отклонение от спецификации:** да, см. раздел «Отклонения» в индексе

- **Статус:** done

## Что сделать

`enum` или `record LinuxSyscalls(setattr, getattr)` по архитектуре:

- x86_64 → 314 / 315;
- aarch64 → 274 / 275;
- опционально riscv64 и loongarch64 (asm-generic, те же 274 / 275).

Выбор один раз при инициализации provider; неподдержанная архитектура → noop с `unsupportedReason`.

## Готово, когда

Unit-тест на выбор номеров по `os.arch`.

## Результат

`record LinuxSyscalls(setattr, getattr)`: x86_64 → 314/315 (syscall_64.tbl), aarch64 → 274/275 (asm-generic unistd.h), сверено с torvalds/linux master. riscv64/loongarch64 намеренно не добавлены (не протестированы на железе, §14 «не угадывать»). Неподдержанная архитектура → `NoOpThreadQosProvider` с `unsupportedReason`. Unit-тест на выбор по `os.arch`.
