## Что сделать

В README:

- uclamp влияет на частоту только через governor `schedutil`, на placement только на CPU с асимметричной capacity;
- на x86 с `intel_pstate` active или `performance` эффекта практически нет;
- `util_max` не уменьшает долю CPU-времени;
- RT/deadline потоки вне контракта;
- seccomp и контейнеры;
- статус в таблице §57 со сноской.
