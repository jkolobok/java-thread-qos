- **Этап:** Этап 4. Windows
- **Тип:** задача

- **Отклонение от спецификации:** нет

- **Статус:** done

## Что сделать

Mapping §9.1 через один `switch` в record `WindowsQosState(controlMask, stateMask, priority)`.

Порядок: throttling (если поддерживается), затем priority. Никаких `THREAD_PRIORITY_TIME_CRITICAL`, `REALTIME_PRIORITY_CLASS`, `THREAD_MODE_BACKGROUND_*`.

## Готово, когда

Integration test на пять классов; readback `GetThreadPriority` и `GetThreadInformation` совпадают с mapping.

## Результат

`WindowsQosState.of(QosClass)` — единственный `switch`; порядок: throttling (если поддерживается) → priority; TIME_CRITICAL/REALTIME/BACKGROUND_MODE не используются (тест `neverUsesForbiddenPriorities`). Integration-тест `setThenReadBack` сверяет `GetThreadPriority` и `GetThreadInformation` с mapping (тег `abi`); прогон — на `windows-latest`.
