- **Этап:** Этап 4. Windows
- **Тип:** задача
- **Спецификация:** §8.1, §9.3, §9.4, §75, §89
- **Отклонение от спецификации:** да, см. раздел «Отклонения» в индексе
- **Зависит от:** [T-2.8](../02-public-api/T-2.8-ffm-support.md)
- **Блокирует:** [T-4.2](T-4.2-windows-throttling-layout.md), [T-4.3](T-4.3-windows-capability-probe.md)
- **Статус:** done

## Что сделать

Символы брать через `SymbolLookup.libraryLookup("kernel32", Arena.global())`: `defaultLookup()` на Windows отдаёт только C runtime.

Downcalls:

- `GetCurrentThread() -> ptr`;
- `SetThreadInformation(ptr, int, ptr, int) -> int`;
- `GetThreadInformation(ptr, int, ptr, int) -> int`;
- `SetThreadPriority(ptr, int) -> int`;
- `GetThreadPriority(ptr) -> int`;
- для `Set*` — `Linker.Option.captureCallState("GetLastError")`.

Константы с ссылкой на `processthreadsapi.h`: `ThreadPowerThrottling` (значение сверить по SDK), `THREAD_POWER_THROTTLING_CURRENT_VERSION = 1`, `THREAD_POWER_THROTTLING_EXECUTION_SPEED = 0x1`, `THREAD_PRIORITY_*`.

Pseudo-handle из `GetCurrentThread()` не закрывать.

## Готово, когда

Symbol-resolution тест на Windows проходит (§53).

## Результат

`WindowsQosNative`: `SymbolLookup.libraryLookup("kernel32.dll", Arena.global())`; downcalls `GetCurrentThread`, `SetThreadInformation`, `GetThreadInformation`, `SetThreadPriority`, `GetThreadPriority`, для всех кроме `GetCurrentThread` — `captureCallState("GetLastError")` с per-call confined arena. Константы (`ThreadPowerThrottling=3`, version 1, `EXECUTION_SPEED=0x1`, `THREAD_PRIORITY_*`, `ERROR_*`) сверены с публичными SDK-заголовками (winbase.h, processthreadsapi.h, winnt.h, winerror.h). Pseudo-handle не закрывается. Symbol-resolution тест — в `WindowsIntegrationTest` (выполняется на `windows-latest`).
