## Что сделать

`StructLayout` из трёх `JAVA_INT` (12 байт, alignment 4); поле `Version` всегда `THREAD_POWER_THROTTLING_CURRENT_VERSION`.

## Готово, когда

Тест на size/offsets.

## Результат

`ThreadPowerThrottlingState.LAYOUT` = 3 × `JAVA_INT` (12 байт, alignment 4), `write()` всегда пишет `Version=1`. `ThreadPowerThrottlingStateTest`: size/alignment/offsets/ширины, порядок байт.
