## Что сделать

`central-publishing-maven-plugin` (актуальную stable-версию сверить на момент фиксации POM); POM-метаданные §35; credentials только из GitHub Secrets (§39).

## Готово, когда

Dry-run публикации (`publishingServerId` + validation без release) проходит.

## Результат

`central-publishing-maven-plugin` 0.11.0 (актуальная stable по maven-metadata на 2026-09-26), `publishingServerId=central`, `autoPublish` через свойство `central.autoPublish`, `waitUntil=published`; POM-метаданные §35 (name, description, url, license, developer, scm, issueManagement). Credentials только из `~/.m2/settings.xml` / GitHub Secrets. Dry-run загрузки невозможен без Portal-токена — описан в RELEASING.md.
