- **Этап:** Этап 8. Release engineering

- **Отклонение от спецификации:** нет

## Что сделать

Профиль `release` с `maven-source-plugin`, `maven-javadoc-plugin`, `maven-gpg-plugin`; подпись всех артефактов §37.

## Готово, когда

Локальный `mvn -Prelease verify` даёт четыре подписанных артефакта.

## Результат

Профиль `release`: `maven-source-plugin:jar-no-fork`, `maven-javadoc-plugin:jar`, `maven-gpg-plugin` (bestPractices, pinentry loopback, passphrase из `MAVEN_GPG_PASSPHRASE`). Локально `mvn -Prelease -Dgpg.skip verify` даёт jar + sources + javadoc; подпись проверить нельзя — на машине нет GPG-ключа (владелец создаёт по RELEASING.md).
