## Что сделать

Переписать §29, §31, §47: на JDK 22–25 restricted-вызов без `--enable-native-access` даёт одноразовое предупреждение, а не исключение; `IllegalCallerException` возникает только при `--illegal-native-access=deny`. Библиотека должна проверять `Module.isNativeAccessEnabled()` и давать подсказку проактивно.

## Готово, когда

Разделы переписаны; negative test в §47 описан для режима `deny` и для проверки текста подсказки.

## Результат

§29 переписан (таблица режимов `--illegal-native-access`), §31 — каноническое описание диагностики с проверкой `isNativeAccessEnabled()` и текстом подсказки, §47 — два negative job’а (`deny` и `warn`).
