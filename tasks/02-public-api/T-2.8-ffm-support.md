## Что сделать

Общий `Linker`; утилиты создания downcall handle с оборачиванием linkage-ошибок в `ThreadQosException`; helper для per-call `Arena.ofConfined()`.

Явно запретить статический shared segment для `captureCallState`: параллельные `set()` из разных потоков затрут друг другу errno/GetLastError.

## Готово, когда

Класс покрыт unit-тестом на оборачивание `NoSuchElementException`.

## Результат

Общий `LINKER`, `downcall(...)` с оборачиванием `IllegalCallerException | NoSuchElementException | IllegalArgumentException | UnsupportedOperationException | WrongMethodTypeException`, `libraryLookup`, `captureStateLayout()` / `captureStateHandle(name)`. Запрет статического segment для captured state задокументирован в javadoc класса. `FfmSupportTest` проверяет оборачивание `NoSuchElementException` и реальный downcall `strlen`.
