## Что сделать

Maven-профиль `benchmarks` (JMH не в runtime-зависимостях): `isSupported()`, `set()`, overhead `wrap()`. Без «наносекундных» заявлений в README.

## Готово, когда

`mvn -Pbenchmarks verify` собирает бенчмарки.

## Результат

Профиль `benchmarks`: JMH 1.37 только в test scope профиля, `src/jmh/java` через build-helper, annotation processor, `exec:exec` для запуска (`mvn -Pbenchmarks verify exec:exec`, фильтр `-Djmh.args`). Бенчмарки: isSupported, capabilities, set(DEFAULT/USER_INTERACTIVE), trySet, baseline, wrapCreate, wrapRun. `mvn -Pbenchmarks verify` собирает бенчмарки. В README нет наносекундных заявлений.
