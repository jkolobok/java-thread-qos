## Что сделать

Downcall `qos_class_self() -> int` (без memory segments) для тестов и capability `nativeReadbackSupported=true`. В публичный API не выносить.

## Готово, когда

Round-trip тест «set → qos_class_self == ожидаемая константа» для всех классов.
