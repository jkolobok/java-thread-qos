## Что сделать

Lazy, read-only, результат кэшируется в `volatile`/holder.

Шаги: `sched_getattr(0, attr, 56, 0)`:

- `ENOSYS` → unsupported («syscall unavailable»);
- `EPERM` → unsupported («denied by seccomp/security policy»);
- успех с возвращённым `size < 56` → unsupported («kernel older than 5.3»);
- успех с `size >= 56` → кандидат.

Первый `set()` с `EOPNOTSUPP` → перевести в unsupported («kernel built without CONFIG_UCLAMP_TASK») и кэшировать, без исключения.

`isSupported()` и `capabilities()` запускают probe.

## Готово, когда

Unit-тест с подменённым нативным слоем на каждый исход; integration test печатает результат probe в CI output.

## Результат

Lazy read-only probe (`volatile` state + synchronized slow path): ENOSYS/EPERM/прочие errno/size<56 → unsupported с причиной; size≥56 → кандидат; первый `set()` с EOPNOTSUPP → unsupported без исключения (кэшируется). `isSupported()`/`capabilities()` запускают probe. Unit-тест с фейковым ядром на каждый исход; integration-тест печатает результат probe (`[linux] uclamp SUPPORTED/UNSUPPORTED: …`). Переход по EOPNOTSUPP подтверждён на реальном ядре linuxkit 7.0 без CONFIG_UCLAMP_TASK.
