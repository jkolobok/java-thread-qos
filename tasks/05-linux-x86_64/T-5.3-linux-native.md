- **Этап:** Этап 5. Linux x86_64
- **Тип:** задача

- **Отклонение от спецификации:** да, см. раздел «Отклонения» в индексе

- **Статус:** done

## Что сделать

Downcall `syscall` из `defaultLookup()` с обязательным `Linker.Option.firstVariadicArg(1)` и `captureCallState("errno")`.

Два descriptor'а:

- `sched_setattr(long nr, int pid, ptr attr, int flags) -> long`;
- `sched_getattr(long nr, int pid, ptr attr, int size, int flags) -> long`;
- `pid = 0`.

Константы флагов с ссылкой на `include/uapi/linux/sched.h`: `SCHED_FLAG_KEEP_POLICY`, `SCHED_FLAG_KEEP_PARAMS`, `SCHED_FLAG_UTIL_CLAMP_MIN`, `SCHED_FLAG_UTIL_CLAMP_MAX` (значения сверить по headers перед фиксацией).

## Готово, когда

Symbol-resolution тест на Linux проходит; в коде есть тест-guard на наличие `firstVariadicArg`.

## Результат

`LinuxQosNative`: downcall `syscall` из `defaultLookup()` с `firstVariadicArg(1)` и `captureCallState("errno")` (per-call arena); два дескриптора (setattr: long,int,ptr,int → long; getattr: long,int,ptr,int,int → long), `pid=0`. Флаги `KEEP_POLICY=0x08`, `KEEP_PARAMS=0x10`, `UTIL_CLAMP_MIN=0x20`, `UTIL_CLAMP_MAX=0x40` сверены с include/uapi/linux/sched.h. Symbol-resolution тест `syscallSymbolResolvesAndVariadicBindingWorks` реально выполнил `sched_getattr` в Docker (arm64: size=56, policy=SCHED_OTHER).
