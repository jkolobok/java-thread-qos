## Что сделать

На x86-серверах с `intel_pstate` active или governor `performance` uclamp не влияет ни на частоту, ни на долю CPU-времени, то есть `BACKGROUND` не перестаёт конкурировать с `USER_INTERACTIVE`.

Варианты:

- (a) оставить v1 только на uclamp и честно документировать;
- (b) добавить nice / `SCHED_IDLE` для нижних классов.

Рекомендация: (a) для v1, потому что понижение nice необратимо без `CAP_SYS_NICE`; (b) вынести в явный expert API v2 (§63).
