## Что сделать

Отдельный workflow на tag `vX.Y.Z`: checkout → JDK 25 → `mvn verify` → sign → publish Central → GitHub Release (changelog, координаты, min Java, заметка про `--enable-native-access`, список ОС/архитектур, ссылка на Central).

Secrets доступны только этому job; forks их не получают. Guard от повторной публикации существующей версии (проверка наличия версии в Central перед deploy).

## Готово, когда

Тестовый прогон workflow на tag `v0.1.0-rc` проходит все шаги до publish.
