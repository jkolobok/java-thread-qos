## Результат

Код, CI, документация и release-workflow готовы (scope §91 реализован: macOS, Windows, Linux x86_64/aarch64, portable API). Сам релиз требует ручных шагов владельца: (1) создать GitHub-репозиторий `jkolobok/java-thread-qos` и запушить; (2) дождаться зелёного CI на всех runner’ах (Windows/Linux uclamp проверяются только там); (3) Central Portal аккаунт + namespace + token, GPG-ключ, четыре secrets; (4) тег `v0.1.0-rc1` для dry-run, затем `mvn versions:set -DnewVersion=0.1.0`, дата в CHANGELOG, тег `v0.1.0`.
